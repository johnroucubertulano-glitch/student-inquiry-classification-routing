# Machine Learning-Based Student Inquiry Classification and Routing System

## Project Description

This project is a Machine Learning-Based Student Inquiry Classification and Routing System that helps classify student inquiries and route them to the appropriate office.

## Development Methodology

The project uses **Scrum (Agile/Adaptive)** as its primary development methodology.

## Development Workflow

The team follows a sprint-based workflow:

**Product Backlog → Sprint Planning → Design → Development → Testing → Sprint Review → Feedback → Next Sprint**

The project is developed incrementally through short sprints. Each sprint includes planning, development, testing, review, and improvement based on feedback.

## Version Control and Delivery

Git and GitHub are used for version control and collaboration. Changes are committed regularly and reviewed before integration. Testing and CI/CD practices are used to support reliable integration and delivery.

## Project Milestones

The major milestones include:

* Requirements and planning
* System design
* Database development
* Student inquiry submission
* ML classification and routing
* Admin and response features
* Testing and improvement
* Final integration and deployment
